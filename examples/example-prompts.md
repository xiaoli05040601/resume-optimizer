# Example Prompts

## 1. Resume Tailoring For A Specific JD

```text
帮我根据这份 JD 优化简历。

【JD】
Senior Product Manager, Merchant Platform
...

【我的背景】
- 3 年电商产品经验
- 做过商家后台工具
- 会 SQL 和基础 Python
...
```

## 2. Hackathon Application Materials

```text
我想报名这个 AI Hackathon，请根据活动要求帮我整理报名材料。

【活动要求】
- 需要项目 idea
- 需要个人简介
- 需要技术背景说明
...

【我的背景】
- 机器学习工程师
- 做过医疗影像 AI
- 有 Gemini API 使用经验
...
```

## 3. Convert LinkedIn Into A Stronger Resume

```text
我把 LinkedIn 资料贴给你，你帮我转成适合这个岗位的英文简历。

【JD】
Senior Backend Engineer
...

【LinkedIn 资料】

```

## 4. Ask For Gap Analysis First

```text
先别急着写简历，先告诉我这份 JD 和我现在的背景差距在哪里，再决定怎么改。
```

## 5. Optimize For AI-Era Hiring Traits

```text
我想投一家 AI 创业公司的内容/产品实习。先按好奇心、靠谱、事实洁癖、多元化思维、能忍受不确定性、低 ego 高自驱这六项标准诊断我的简历，再帮我改。

【我的材料】
- 最近一个月测试过 Claude Code、Runway、即梦和扣子，写了 8 篇工具测评
- 负责过一个公众号栏目，每周三固定更新，连续 12 周没断更
- 做内容前会查原始发布页和官方文档，纠正过 AI 给出的错误产品发布时间
- 本科广告学，但也长期写科技产品、读心理学和经济学
- 做过一个新栏目试点，前 3 期数据不好，后来改选题角度后阅读率提升
- 经常主动发起选题，但会根据编辑反馈重写结构
```
